# Общий слой движка

Норма TASK_ARCH_001 v2.2, К-1. Реорганизация реализована этапом 6.

## Общая модель

Core предоставляет модели сущностей, payload, чанков и связей и повторно
используемые алгоритмы. EF DTO и физические форматы таблиц внутрь модели
не включаются. Модель чанка не обязывает переносить всю физическую схему Geo4.

## Сервисы

BusinessEntityHelper остаётся общим движковым API. Фабрики, валидация имён,
графовые операции и формирование пакета не копируются в каждый миниапп.
Обычный DI и состояние с определённым временем жизни допустимы.

Операции хранения выполняются через публичный коннектор DataProvider и шину.
Core не получает DbContext, репозиторий или внутренний кодек миниаппа.

## Описатели типов

Создание конкретного payload, имена, допустимое вложение и состав сохранения
задаются описателем типа, зарегистрированным владельцем в AddXxxMiniApp.
Общий сервис работает через реестр описателей. В нём нет switch по реализациям
Document, RichTextDocument, MediaVideo, Space, Folder и SysParameters.

Из контрактов миниаппов Core может ссылаться только на Contracts DataProvider.
Описание конкретного предметного типа и его политика принадлежат владельцу.
Архитектурные проверки отличают эту разрешённую ссылку от доступа к внутренностям.

## Разделение ответственности

Общий алгоритм остаётся в Core; предметный сценарий — у владельца миниаппа;
технический механизм — в Infrastructure; постоянная запись — в DataProvider.
При разборе смешанного хелпера классифицируется каждый метод.
Удаление всего хелпера ради уменьшения общего слоя запрещено.

Источник: [ТЗ §3.1](../Tasks/TASK_ARCH_001_miniapp-bus-architecture-migration.md#31-общий-слой-и-границы-миниаппов).

## Реализованный контракт

IEntityTypeDescriptor и EntityTypeRegistry находятся в Core/Types. Общая фабрика
использует metadata владельца; Core не содержит предметных enum-членов.
Initial payload/chunks, clone и type-specific правила объявляет Registration владельца.
Дубликат/неизвестный тип даёт явный отказ. Required singleton читается без создания;
инициализацию выполняет startup runtime владельца.

Общие BusinessEntityDataChunk/Block находятся в Core/Chunks. JSON kind физического
чанка остаётся RichTextDocumentChunk. Его envelope/codec — публичный технический
контракт DataProvider. Payload-модели и конкретные converters — у владельцев.

Move/Delete набора готовит одну транзакцию. Save использует независимые копии до
await. Архитектурные тесты проверяют CLR-сигнатуры, тела исходников и Razor, включая
чужие Internal/Components/Storage/Repositories/Facade.
