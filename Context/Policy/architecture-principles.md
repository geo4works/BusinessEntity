# Архитектурные принципы BusinessEntity

Норма TASK_ARCH_001 v2.2, 2026-10-28. Применение проверяется по этапам ТЗ;
описание целевой архитектуры не означает, что все этапы уже реализованы.

## Состав системы

BusinessEntity — база знаний с навигацией по страницам. Один процесс обслуживает
несколько пользователей и окон браузера. Между миниаппами действует одна
ReactiveUI IMessageBus. Постоянное хранение графа — PostgreSQL и внешний storage.

- Core содержит общие Entity, Data, Chunk, Relation, контракты и сервисы движка.
- Infrastructure предоставляет шину, корреляцию, модульность, сохранение и диагностику.
- MiniApp изолирует предметный домен, его состояние, операции и интерфейс.
- DataProvider применяет пакеты изменений и владеет физическим хранением графа.
- Оболочка предоставляет геометрию и именованные места.
- Host-service публикует только декларации; runtime создаёт менеджер.

## Границы

Общий BusinessEntityHelper сохраняется и используется через DI. Конкретные типы
публикуют описатели от миниаппов-владельцев; Core не знает их реализаций.
Core может использовать только публичные Contracts DataProvider.
Межминиаппный коннектор вызывает шину. Доступ к чужим Internal, Components,
Facade, Repositories и Storage запрещён. Проверки выполняются в одном проекте;
отдельные сборки на миниапп не требуются.

## Сохранение

Рабочий экземпляр миниаппа владеет набором редактируемых сущностей и dirty.
Один Save отправляет одну транзакцию в DataProvider. Атомарность БД,
согласованность файлов и исход операции входят в обязанности хранения.
История и сроки хранения определяются типом. Версии пространства, глобальный
Save и dirty пространства не вводятся.

## Интерфейс

Модули размещаются на страницах, в местах оболочки и работают без UI.
Внутренние вкладки, лента и TabbedHostArea отсутствуют. Для двух страниц
пользователь открывает второе окно браузера. Кнопки и меню — декларации.
Guard доступа выполняется и на серверной границе операции.

## Данные и ошибки

Обратная совместимость не поддерживается. Старые поля, обёртки, форматы,
миграции и догоняющие backfill удаляются в затрагивающем их пакете.
Несовместимая схема или неизвестный формат дают явную ошибку.
Удаление volumes и файлов всё равно требует явного согласия пользователя.
